# Resume Chat

A Next.js chat interface that answers questions using resume and interview material retrieved from a vector database.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). Configure the required environment variables in the local environment before using the chat API.

## Verify

```bash
pnpm format:check
pnpm lint
pnpm compile
pnpm build
```
